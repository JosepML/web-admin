# Web de Josep Mira Lozano

Web nueva en construcción (Next.js + Supabase). La web publicada actualmente sigue en la rama `master`; el código antiguo está en `legacy/` para migrar su contenido.

## Verla en tu ordenador

Requisito: [Node.js](https://nodejs.org) 20 o superior.

```bash
npm install
npm run dev
```

Abre http://localhost:3000.
