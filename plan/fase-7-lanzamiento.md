# Fase 7: Pruebas y lanzamiento

**Estado:** Bloqueada (necesita la fase 6)

## Objetivo

Publicar la web nueva en un solo paso controlado, con la antigua lista para volver atrás.

## Decisiones necesarias antes de lanzar

- [ ] Dominio (¿tiene uno? ¿comprarlo?)
- [ ] Alojamiento: Vercel Pro para uso comercial (confirmar precio actual) u otra opción
- [ ] Fecha y hora del lanzamiento (poco tráfico)

## Antes de publicar

- [ ] Todas las fases aprobadas y la lista de cambios cerrada
- [ ] Recuento final: 18 proyectos (14 trabajos y 4 recreaciones), 2 artículos, Recreaciones y páginas fijas visibles
- [ ] Formulario probado: llega el correo y aparece en el panel
- [ ] GA4 recibiendo visitas
- [ ] Redirecciones de direcciones antiguas probadas
- [ ] Velocidad en verde en móvil y ordenador; accesibilidad y enlaces revisados
- [ ] Copia de la web actual en una etiqueta de git `web-antigua`

## El día del lanzamiento (solo con la orden expresa de Josep)

1. Fusionar la rama de trabajo en `master` en un único commit.
2. Publicar en el alojamiento elegido y apuntar el dominio.
3. Dejar en GitHub Pages solo una redirección a la dirección nueva.
4. Enviar el mapa del sitio a Google Search Console.
5. Comprobar la web en vivo página a página.

## Vuelta atrás

Volver a publicar la etiqueta `web-antigua` en GitHub Pages y devolver el dominio; el contenido nuevo sigue en la base de datos.
